RustX WASM - Basic Examples

This page demonstrates the reactive features of rustx-wasm using declarative HTML attributes.

1. Simple Button Click

Click the button to fetch content from the server.

Result will appear here...
View HTML 
<button
    rx-action="/api/hello"
    rx-target="#result1"
    rx-swap="innerHTML">
    Click Me
</button>

2. Form Submission

Submit the form to send data to the server.

Form result will appear here...
View HTML 
<form rx-action="/api/submit" rx-target="#result2">
    <input type="text" name="username" required>
    <input type="email" name="email" required>
    <input type="submit" value="Submit">
</form>

3. Different Swap Modes

Try different ways to insert content.

Initial Item
View HTML 
<button rx-action="/api/item" rx-target="#list" rx-swap="beforeend">
    Append Item
</button>
<button rx-action="/api/item" rx-target="#list" rx-swap="afterbegin">
    Prepend Item
</button>

4. Custom Trigger (Change Event)

The request is triggered on input change instead of click.

Select an option to see the result...
View HTML 
<select
    rx-action="/api/select"
    rx-trigger="change"
    rx-target="#result4">
    <option value="option1">Option 1</option>
</select>

5. POST Method

Send data using POST method.

Click the button to create an item...
View HTML 
<button
    rx-action="/api/create"
    rx-method="POST"
    name="action"
    value="create"
    rx-target="#result5">
    Create Item
</button>
