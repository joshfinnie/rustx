Welcome to the RustX History Support Demo!

This page demonstrates the new history features:

  • rx-push-url - Push new URL to history (creates back button entry)
  • rx-replace-url - Replace current URL (no back button entry)
  • rx-push-title - Set custom page title in browser history

Current scroll position will be preserved when you navigate back!
