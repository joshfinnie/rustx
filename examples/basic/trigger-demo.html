RustX Trigger Modifiers & Filters

1. The "once" Modifier

Click this button multiple times - it will only work once!

rx-trigger="click once"
Waiting for first click...
Use case: One-time actions like accepting terms, dismissing notifications, or tutorial steps.

2. The "changed" Modifier

Type in the input and blur - request only fires if the value actually changed!

rx-trigger="blur changed"
Blur the input after changing the text...
Use case: Auto-save forms only when values actually change, preventing unnecessary server requests.

3. The "delay" Modifier

Hover over the button - request fires 1 second after mouseenter!

rx-trigger="mouseenter delay:1s"
Hover over the button...
Use case: Debouncing user input, showing previews on hover, delayed tooltips.

4. Trigger Filters - Control Key

This button only works when you Ctrl+Click (or Cmd+Click on Mac)!

rx-trigger="click[ctrlKey]"
Try Ctrl+Click or regular click...
Use case: Power user shortcuts, special actions with modifier keys.

5. Trigger Filters - Shift Key

This button only works when you Shift+Click!

rx-trigger="click[shiftKey]"
Try Shift+Click or regular click...
Use case: Multi-select operations, alternative actions.

6. Combined: delay + filter

Ctrl+Click this button - it will delay for 500ms before triggering!

rx-trigger="click[ctrlKey] delay:500ms"
Ctrl+Click and wait...
Use case: Complex interactions combining multiple conditions.

7. Mouse Enter + Once

Hover over this div - it loads content only on first hover!

rx-trigger="mouseenter once"
Hover Over Me!
Not hovered yet...
Use case: Lazy-loading content on first interaction, one-time tooltips.
